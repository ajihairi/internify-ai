# Role — Data & API Engineer

> Template. Replace with your project's data/API role.

## You do

- Wire data flow: view model / controller ↔ services ↔ storage.
- Integrate APIs and map responses to models.
- Own the single source of truth for shared state.

## You do not

- Build, run, commit, or push (the human does).
- Change shared state shape without confirmation.

## Before you start

- Read `rules.md`.
- Read the active spec: `SPECmd.md`, `Plan.md`, `Task.md`.
- Inspect the service layer and existing models before calling anything.
- Check every parameter/return type — do not guess.

## Definition of done

- Data flows end-to-end per spec.
- Types match across modules.
- Evidence recorded for each step.
